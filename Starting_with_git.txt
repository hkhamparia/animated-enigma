git branch -M main------------------------Renames your current default branch to main.
git push -u origin main--------------Uploads your code to the main branch on the remote server (origin).


===========================================

git status--------------------------Show current state of repository
git log-------------------------Show commit history
git diff------------------Show differences between files
git pull origin main----------------------Fetch and merge updates from remote
git fetch origin----------------------Download changes without merging
git remote -v-------------------------Show remote repositories
git reset file1.txt-----------------------Undo staging or commits
git rm file1.txt-------------------------------Remove a file from repository
git stash------------------------------------Temporarily save changes
git stash pop-------------------------------Restore stashed changes
